# 地图目录视觉精修设计

**日期：** 2026-08-09

**状态：** 用户已选择方案 A「柔和立体水滴」

**基线：** `docs/superpowers/specs/2026-08-06-scalable-map-venue-directory-design.md`

## 目标

只精修地图页已有的定位针、搜索/定位控件和场馆卡片，不改变信息架构、搜索逻辑、筛选逻辑或后端契约。

## 定位针

- 所有场馆采用同一套圆润水滴轮廓，使用轻微顶部高光、柔和投影和中心圆点形成克制的立体感。
- `ONLINE` 使用品牌蓝实心针；`DIRECTORY_ONLY` 使用白色主体、品牌蓝描边。除颜色外，实心与空心结构也提供语义区分。
- 选中状态只增加固定光环并略微放大图形资源；不得出现方形底图、文字气泡或布局跳动。
- 不复制 Google Maps 或第三方图标，使用项目自有矢量源生成本地 PNG，确保微信 `<map>` 标记兼容和授权清晰。

## 搜索与定位控件

- 顶部工具区使用“搜索栏自适应填满 + 48×48 px 等效定位按钮”的两列布局，左右边距和间距保持 8 px 节奏；44 px 仅作为其他触控目标的最低门槛。
- 搜索栏与定位按钮同高；搜索栏保留放大镜和清除入口，定位按钮使用与搜索图标一致的线宽和圆角语言。
- 定位按钮 idle、requesting、active、error 均保持固定尺寸；active 使用浅蓝底和蓝色描边。

## 三行固定卡片

- 卡片固定三行：场馆名称；地址；“距离/交通摘要 · 业务状态”。
- `可在线预订` 或 `仅提供场馆信息` 合并到第三行，不再单独占据第一行。
- 尾部箭头保持 44×44 px 等效触控区；卡片选中仅改变内描边和浅色背景，不改变高度、文字行数或箭头位置。
- 长名称、地址和摘要单行省略，50 家以上目录仍采用纵向滚动。

## 验收

- 通过现有单元测试、类型检查、lint 和开发构建。
- 在 375×812 与 390×844 视口生成实现图、并排图和叠加/差异图；视觉确认前不进入后端阶段。
