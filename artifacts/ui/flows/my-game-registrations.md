# C1c-1 我的报名 · Artifact flow

本 Artifact 是 `production-disabled` 的 `375 × 812` 开发参考稿，只冻结“找球局入口 → 我的报名 → 精确详情 → 返回保留状态”的页面、交互和隐私边界，不创建生产路由、接口或数据。

`entry → ready-list`：找球局内容区先显示“我的报名”入口，再显示公开球局筛选。日期、人制和仅看有名额使用 AND 组合；筛选、清除筛选和公开球局整卡导航都更新真实内存状态。进入“我的报名”前保留筛选与 entryScrollTop，标题栏返回后精确恢复。

`ready-list → refresh`：刷新重新投影第一页，稳定 key 按 registration ID 去重，因此刷新不重复。`ready-list → load-more`：游标 `c1c-page-2` 只读取一次，第二页只追加一次，再点不会重载或重复。

`ready-list → detail → ready-list`：报名整卡是唯一详情入口，按 registration ID 打开与卡片一致的只读详情。从列表打开时，标题栏返回或显式返回都保留已加载列表、游标和 listScrollTop；独立深链没有 Artifact 历史时返回找球局入口。未知报名不回退第一条，并遵循同一来源返回语义。

`empty`：空列表是成功结果，刷新仍为空；标题栏可以返回找球局。`load-error → ready-list`：重新加载读取稳定第一页，不制造新的报名或成功假象。

卡片只呈现状态、球局名称、日期/时间、场馆、物理场地与人制。隐私禁止项包括个人称呼、说明文字、审核角色、其他参与者、联系方式、订单、支付与成员列表。四种有效状态文案为“待队长审核 / 已加入 / 未通过 / 球局已取消”，状态以服务端为准。

所有可见控件都绑定状态更新或浏览器 history；整卡没有嵌套操作，控件至少 `44px` 并显式 flex 双轴居中。Reference 自审通过后仍保留用户视觉门 `PENDING`，不得据此进入生产集成。
