# C2d 到场人工纠错回读 · Artifact flow

本 Artifact 是 `production-disabled` 的 Development-only Fixture，只冻结平台纠正后的两张移动端只读回读页，不创建生产路由、接口或数据。代表视口为 iOS `390 × 844` 与 Android `411 × 731`；同一页面允许纵向滚动，底部保留 safe area。

`captain`：队长的“到场记录”页展示目标散客的当前有效状态、原始记录时间、最新平台纠正时间与报名编号。长本场称呼可换行，结果徽标独立对齐，不覆盖队长首次记录。页面不提供再次标记或平台纠正操作。

`player`：球员本人的“报名详情”回读当前有效状态、原始记录时间、最新平台纠正时间与同一报名编号。页面明确写出“平台已纠正”，但不展示纠正原因、平台 principal、完整历史、联系方式、用户 ID、报名备注、同意字段、订单、支付或退款信息。

两页的“复制报名编号”均调用真实 Clipboard API adapter。调用成功后，紧邻按钮的 `role=status` 区域显示“报名编号已复制”；权限拒绝、API 不可用或写入异常时显示“复制失败，请重试”，按钮恢复可用并允许再次调用。返回按钮调用宿主 history，不伪造成功状态。

Manifest 只冻结四个代表画面：平台 `ready / confirm` 与移动端 `captain / player`。移动端两页分别在两个设备视口捕获，不扩张为全状态截图矩阵。当前视觉与真机验收门保持 `PENDING`。
