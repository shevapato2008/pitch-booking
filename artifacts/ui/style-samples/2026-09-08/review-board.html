ZHUGUANG · DESIGN EXPLORATION / 01

同一场热爱，三种上场方式。

找球局 → 球局详情 → 报名面板。先选气质，再展开整个产品。

A

夜场追光

深海蓝 / 荧光青柠 / 聚光灯

更沉浸，更有上场仪式感。
深色球场、发光边缘和大号时间。适合突出夜场、运动和年轻感。

B

晴空竞技

冰川白 / 电光蓝 / 轻盈浮层

清透利落，日常使用很舒服。
明亮底色、浮起的白卡片和蓝色节奏。延续现有界面，增加运动气质。

C

复古球票

奶油纸 / 朱砂橙 / 俱乐部

更有个性，也更有足球文化感。
球票齿孔、虚线和复古数字。像一张值得收藏的比赛门票。

三套均为微信开发者工具原生运行截图，目标设备 iPhone 12/13 (Pro)，逻辑尺寸 390 × 844，基础库 3.17.0。此页用于并排看静态设计；在已打开的微信开发者工具样板项目中，可体验筛选、详情、弹层和动效开关。
